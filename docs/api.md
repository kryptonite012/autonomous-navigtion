# API reference

Base URL: `http://<robot-ip>:8000`. Interactive docs (Swagger UI) are served
at `/docs` and the OpenAPI schema at `/openapi.json`
(a copy is in [`openapi.json`](openapi.json)).

## Authentication

```bash
TOKEN=$(curl -s -X POST http://robot:8000/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"..."}' | jq -r .access_token)
curl -H "Authorization: Bearer $TOKEN" http://robot:8000/api/robot/state
```

* Tokens are signed (HS256) and reference a server-side session, so logout
  and password changes revoke them immediately. Lifetime: `NEXUS_SESSION_MINUTES`.
* 5 failed logins lock the account for 10 minutes; logins are limited to
  10/min per IP.
* Browser resources that cannot send headers (MJPEG stream, downloads)
  accept `?token=`.

## Roles

| Role | Can |
|---|---|
| `viewer` | read everything, **emergency stop** |
| `operator` | + drive, navigate, map, sort, calibrate, manage maps |
| `admin` | + users, safety limits, backups, shutdown, audit log |

## Errors

| Code | Meaning |
|---|---|
| 401 | missing/expired/revoked token |
| 403 | role too low, or client network not in `NEXUS_ALLOWED_NETWORKS` |
| 409 | command refused in the current state (e-stop active, fault, missing hardware, no map, task running …) — `detail` says why |
| 422 | validation error |
| 423 | account locked |
| 429 | rate limit (global 240/min per IP; motion 20/s per user) |

## Motion commands

`POST /api/robot/teleop {"linear": m/s, "angular": rad/s}` must be repeated
at ≥ 2 Hz while driving; the safety watchdog stops the robot 0.6 s after
the last command. The response contains the safety status including the
velocity actually applied and why it was limited.

## WebSocket

`ws://robot:8000/ws?token=<token>` — JSON messages
`{"topic": ..., "ts": unix_seconds, "data": ...}`.

| Topic | Rate | Data |
|---|---|---|
| `hello` | once | user, role, full state |
| `telemetry` | 10 Hz | velocities, battery, ranges, IMU, CPU, loop rate, pose, motor status |
| `pose` | 10 Hz | x, y, theta, valid, source |
| `detections` | 10 Hz | current tracked detections + pipeline stats |
| `navigation` | 10 Hz | state, goal, path, distance, message |
| `state` | 1 Hz | full robot state (safety, mapping, vision, sorting, capabilities) |
| `sorting` | 1 Hz + per record | sorter status, new sort records |
| `map` | 1 Hz while mapping/navigating | RLE occupancy grid + trajectory |
| `events` | on event | runtime events |
| `alerts` | on warning/error | same as events, severity ≥ warning |

Send `{"subscribe": ["telemetry", "alerts"]}` to receive only some topics.
